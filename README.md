# 懇親会 テーブル対抗 クイズアプリ 🎉

懇親会で、テーブル（グループ）対抗のクイズ大会ができるリアルタイムWebアプリです。
主催者がホスト画面で進行を操作すると、参加者全員のスマホに次の問題や結果が**即時に同期表示**されます。

## 特長

- **選択式クイズ**：参加者はスマホで選択肢をタップして回答
- **テーブル別集計**：グループごとに得点を自動集計し、最後にランキング発表
- **主催者主導の進行**：「次の問題」「正解発表」「最終結果発表」をホストが操作 → 全員に同期
- **会場表示（プロジェクタ）画面**付き：問題・正解・順位をスクリーンに大きく表示
- 外部サービス・データベース不要。ノートPC1台で動きます。

## 画面構成

| 画面 | URL | 用途 |
|------|-----|------|
| 参加者 | `/` | 名前とテーブルを入力して参加・回答 |
| 主催者 | `/host` | 進行操作・回答状況・途中経過の確認 |
| 会場表示 | `/display` | プロジェクタ投影用の大画面表示 |

## 使い方

### 1. 起動

```bash
npm install
npm start
```

起動するとコンソールに各URLが表示されます（既定ポート 3000、`PORT` 環境変数で変更可）。

### 2. 当日の運用

1. 主催者のPCでサーバを起動し、`/host` を開く（会場のスクリーンには `/display` を投影）。
2. 参加者は**同じWi‑Fi**で、主催者PCのIPアドレス（例 `http://192.168.0.10:3000/`）にスマホでアクセス。
   - QRコードを作って配ると便利です。
3. 参加者が名前とテーブル名を入力して参加。
4. 主催者が **「▶ クイズを開始 / 次の問題」** → 全員に問題が表示される。
5. 参加者が回答 → 主催者が **「⏱ 締切＆正解発表」** → 正解とテーブル別の回答状況を表示。
6. 全問繰り返したら **「🏆 最終結果を発表」** → テーブル別ランキングを全画面に表示。

> 参加者は同じテーブル名（例「Aテーブル」）を入力した人どうしが同じグループとして集計されます。
> 表記揺れ（"A" と "Aテーブル"）は別グループ扱いになるので、テーブル名は事前に決めて統一してください。

## 問題の編集

`data/questions.json` を編集してください。

```json
{
  "title": "懇親会クイズ大会",
  "pointsCorrect": 100,
  "questions": [
    { "q": "日本で一番高い山は？", "choices": ["富士山", "北岳", "槍ヶ岳", "御嶽山"], "answer": 0 }
  ]
}
```

- `answer` は正解の選択肢のインデックス（0始まり）。
- `pointsCorrect` は1問正解あたりの得点。
- 選択肢は2〜4個（それ以上でも動作します）。
- 編集後は主催者画面の **「↻ 問題を再読込」** で反映できます（得点はリセットされます）。

## 集計ルール

- 1問正解で `pointsCorrect` 点。
- テーブルの順位は**1人あたりの平均点**で決定（人数差があっても公平）。同点の場合は合計点で比較。
- ホスト画面・参加者画面ともに、合計点と平均点を表示します。

## 技術構成

- Node.js + Express（静的配信）
- Socket.IO（WebSocketによるリアルタイム双方向通信）
- 状態はサーバのメモリ上で管理（1回のイベント用。サーバ再起動でリセット）

## 注意事項

- 状態はメモリ保持のため、サーバを再起動すると進行・得点がリセットされます。
- 本番運用の前に一度リハーサル（参加→回答→結果発表）を通しで試すことをおすすめします。
